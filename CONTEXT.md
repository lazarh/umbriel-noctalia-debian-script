# Ubiquitous Language

## Terms

### Umbriel

The Wayland compositor installed by this project. Umbriel includes UmbrielFX in its source tree.

### UmbrielFX

Umbriel's in-tree scene graph and renderer. It is built as part of Umbriel, not treated as a separately installed product.

### Noctalia

The native v5 desktop shell from `noctalia-dev/noctalia`, paired with Umbriel by this project. It does not mean the older Quickshell-based Noctalia Shell v4.

### Installer

The reusable Debian 13 amd64 script whose independently selectable operations install dependencies, Umbriel, and Noctalia.
